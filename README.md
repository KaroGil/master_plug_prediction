# master_plug_prediction

5*, -2C, 400 kg-h = data1
15.6*,-2C,400 kg-h = data2

## Scripts

To run the scripts use

```
python -m script.{script_name}
```

### train.py

Possible parameters: dataset name to specify which dataset is used for traning. Only 1 dataset can be specified as of now, but additional datasets are added manually in the code.
Default: dataset1

```
python -m script.train {dataset name}
```

example

```
python -m script.train data2
```

### predict.py

Predicts the outcome of a given dataset.
Possible parameters: dataset name to specify which dataset is used for traning. Only 1 dataset can be specified.
Default: dataset1

```
python -m script.predict {dataset name}
```

example

```
python -m script.predict data2
```

### predict_all.py

Predicts the outcomes of all datasets present in data/rawdata

```
python -m script.predict_all
```

### delete_files.py

NB! Deletes files generated by train.py. Use with caution.

```
python -m script.delete_files
```

### print_scores.py

Prints the scores for the models.
Used for testing purposes to easily and cleanly see the outcome of model selection.

```
python -m script.print_scores.py
```

### describe.py

Prints the out information about the experimental data used.
Describtions of the dataset to be used to further understand the dataset.

```
python -m script.describe.py
```
